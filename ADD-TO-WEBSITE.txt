RESOURCE BANK — ADD TO YOUR WEBSITE

1. Upload `resource-bank.html` to the SAME level as your `index.html`.

Your repository should now include:

index.html
reading-audit.html
monitor-review-toolkit.html
resource-bank.html

2. Your main index page Resource Bank feature should link to:

<a class="resource-link"
   href="resource-bank.html">
  Explore Resource Bank →
</a>

3. Commit the changes.

4. To add a genuine departmental URL:
   - Open `resource-bank.html`
   - Find the relevant card
   - Replace:

     <a class="resource-link disabled" href="#" aria-disabled="true">Link to be added</a>

   with:

     <a class="resource-link"
        href="PASTE-THE-REAL-URL-HERE"
        target="_blank"
        rel="noopener">
       Open Resource →
     </a>

5. To add a NEW resource:
   - Duplicate one complete <article class="resource-card">...</article>
   - Change:
     * data-category
     * data-search
     * icon
     * category label
     * heading
     * description
     * URL

Available category values:
reading
pedagogy
digital
curriculum
inclusion
leadership
professional-learning

The search and filter functions will work automatically.
