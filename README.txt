# Inquiry Cycle Website

This version is intentionally built as a single self-contained `index.html` file.

## GitHub Pages setup

1. Delete the old project files from the repository, but keep the repository.
2. Upload `index.html` to the root of the `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select:
   - Branch: `main`
   - Folder: `/ (root)`
6. Save.
7. Wait for deployment, then open:
   `https://monei55.github.io/Inquiry-Cycle/`

No GitHub Actions, React, Vite, npm, `src` folder, or workflow file is required.
